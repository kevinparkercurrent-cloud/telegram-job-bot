# Telegram Job Bot

Однопользовательский бот читает до 20 каналов из белого списка через отдельный
Telegram-аккаунт, оценивает вакансии и присылает карточки в управляющего бота.
Отклик отправляется только после нажатия владельцем кнопки подтверждения.

## Что делает бот

- отклоняет вакансии с явно указанной зарплатой ниже 100 000 ₽;
- не отбрасывает вакансии без указанной зарплаты;
- присылает сильные совпадения сразу, пограничные — в 12:00 и 19:00;
- ограничивает отправку откликов: 5 в час и 15 в сутки;
- при неопределённом результате отправки не повторяет сообщение автоматически;
- добавляет к карточке кнопку на исходный Telegram-пост;
- позволяет изменить черновик кнопкой `Редактировать отклик`: следующий текст
  владельца сохраняется как новый черновик, `/cancel` отменяет ввод, а ожидание
  автоматически завершается через 15 минут;
- не передаёт текст Telegram-постов в AI. AI разрешён только для страниц из
  явного списка `EXTERNAL_SOURCE_DOMAINS`; без ключа OpenAI работает шаблон.

## Подготовка Telegram

1. Создайте управляющего бота через `@BotFather` и сохраните токен.
2. Получите `api_id` и `api_hash` для выделенного пользовательского аккаунта на
   `my.telegram.org`.
3. Узнайте собственный числовой Telegram ID — только он сможет управлять ботом.
4. Первый вход пользовательского аккаунта выполняйте интерактивно, чтобы создать
   файл сессии в постоянном Docker volume.

## Настройка

Скопируйте `.env.example` в `.env` и заполните значения. `.env` и Telegram-сессия
исключены из Git. Никогда не публикуйте токены, API hash, SSH-ключи или пароли.

В `EXTERNAL_SOURCE_DOMAINS` указываются только сайты вакансий, которые разрешено
загружать, например `["hh.ru","career.habr.com"]`. Пустой список полностью
отключает внешнее обогащение. Профиль кандидата лежит в
`config/candidate-profile.full.json`.

## Запуск

```bash
docker compose build
docker compose run --rm job-bot python -m job_bot.app
```

При первом запуске Telethon запросит телефон, код и, если включён, пароль 2FA.
После появления `/data/telegram.session` остановите разовый контейнер и запустите:

```bash
docker compose up -d job-bot
docker compose logs -f --tail=100 job-bot
```

Добавление канала в белый список:

```text
/channels add -1001234567890 Название канала
```

Другие команды: `/channels`, `/settings`, `/queue`, `/history`, `/status`,
`/edit <vacancy_id> <текст>`, `/cancel`.

## Развёртывание на VPS

Сначала смените ранее переданный пароль root в панели провайдера. Затем создайте
обычного пользователя, добавьте его SSH-ключ, запретите вход root и парольную
аутентификацию, установите Docker Engine с Compose plugin и клонируйте приватный
репозиторий. Серверу нужен исходящий HTTPS-доступ к Telegram, ЦБ РФ и разрешённым
сайтам вакансий; входящие публичные порты приложению не нужны.

Зашифрованная резервная копия создаётся командой:

```bash
docker compose --profile maintenance run --rm backup
```

Она требует публичного получателя age в `BACKUP_AGE_RECIPIENT`, хранит только
зашифрованные файлы и удаляет копии старше семи дней. Команду следует добавить в
systemd timer или cron на VPS.

Восстановление сначала проверяйте в новом volume: расшифруйте выбранный файл age,
создайте копию production volume, поместите SQLite-файл в копию и запустите
`scripts/smoke_test.py`. Рабочую базу не перезаписывайте до успешной проверки.

Для обновления сохраните текущий commit и резервную копию, выполните `git pull`,
`docker compose build` и `docker compose up -d`. Для отката переключитесь на
сохранённый commit, пересоберите образ и при необходимости восстановите совместимую
копию базы. Если Telegram-сессия отозвана, остановите сервис и повторите только
интерактивную авторизацию. При утечке последовательно замените BotFather token,
API hash/OpenAI key и SSH-ключ, затем пересоздайте контейнер.
